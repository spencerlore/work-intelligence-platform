Pilot guide

A single place to decide what matters next

  1. Capture reliably. Create work manually or paste a message. Every item can retain a source and context.
  2. Route ownership. Personal, delegated, and waiting work are separate attention states — not just labels.
  3. Review risk. The home view exposes overdue work, next-three-day commitments, waiting follow-ups, and delegation health.
  4. Close the loop. Edit status, record follow-ups, complete recurring work, promote an agenda item, or turn an idea into a task.
This is a browser-local pilot. The README describes how the same model evolves into an authenticated, source-of-truth-backed system.
